Meterless is the model path. Nemotron is the model family. Rank stays in the formula on [Ranking](/ranking).

## Route

`engines/runtime_config.py` sets the base URL to `http://127.0.0.1:8088/v1` and the model route to `meterless/deep`. Thinking is disabled. The NVIDIA key stays in Nightshift Providers. The web app does not read it.

Receipts in the published county pack use that route. On the executions that report a model id, the ids are:

- `nvidia/nemotron-3.5-lightning-30b-a3b`
- `nvidia/nemotron-3.5-super-vl-120b-a12b`

`execution_location` on those receipts is `nvidia_cloud`. That is hosted NVIDIA through Meterless. It is not a local GPU load and not an offline DGX Spark run. `paid_fallback_enabled` is false on every execution in the published pack. This pass found zero executions with a paid fallback flag set.

## Not in this submission

H-MEM, World Model, and Markovian are not implemented here. Content Safety and Parse are not demonstrated. Local `meterless/local` is not demonstrated. The engines-branch offline probe is a preflight block with no generation. It is not a DGX result.

`engines/openrouter_backup.py` can call Nemotron only when `OPENROUTER_API_KEY` is set and `PORCHLIGHT_OPENROUTER_BACKUP` is enabled. That module is not the runtime path. No OpenRouter spend is claimed. Leave the flags unset for the demo.

The Milton sheet's own model status is `grounding_partial`: 15 passed drafts and 3 failed, Super VL, on formula `manatee-development-v1`. Rank 1 (DaVita Manatee Bay, CCN `682766`) is one of the failures. The first passed draft on that sheet is rank 4.
