Every ranked row on the hosted sheet has an evidence record. Open it from the row. The drawer is `web/src/components/evidence-drawer.tsx`.

## What you should see

1. **Observed.** The CMS certification number (CCN) and the directory phone, with the CMS source URL when the phone status is `available`.
2. **Audited.** Zetaris query ids for that county chain. Data access mode on these snapshots is `zetaris`.
3. **Fixed policy.** `score.formula_version`.
4. **Draft or computed reason.** If `model_explanation.status` is `passed`, the drawer shows the stored draft and says grounding passed. If status is `failed`, it says no approved draft and does not invent a replacement. The line above the spine, `computed_reason`, is the formula sentence either way.

A passed national draft carries `model_id`, `mode` (`meterless/deep`), `provider` (`nvidia`), `trace_id`, `actual_usd`, `questions`, and `grounding`. Grounding method on the Doña Ana rank 1 row is `exact_source_clause_catalog_v1`. Clause ids are `cms_rating`, `tract_svi`, and `zip_context`. The scope string says this is source-clause identity, not clinical validation. `operator_review_required` is true.

Each county snapshot also stores the audited SQL text and vendor query hash per chain step. Seven steps is the national chain the drawer headings expect.

## Sources on the row

`evidence.sources` lists dataset name, URL, and license. `evidence.data_as_of` lists fetch time and a stale flag. A stale flag is not a promise about current conditions. SHA-256 fields cover the source artifact and the published JSON sidecar.

Coordinates are printed with a short display and the source value. Unknown coordinates stay unknown. The drawer does not invent a pin.

## Contract fields that are not this drawer

The contract `Evidence` type also names `ledger_ids` and a join `seen_before` flag whose description mentions H-MEM. Those fields are in `contract/openapi.yaml`. The hosted national drawer does not present an H-MEM memory, a TrustLedger, or a World Model. Scout Intent shows up when a **local** call script returns a contract. It is not attached to the published county GET.

Export on the hosted sheet is the operator CSV and print path in the browser. It is not `POST /runs/{id}/export` from the contract. See [API reference](/api-reference/introduction).
