emPOWER tells you how many. Porch Light tells you who to call first, and why.

<Frame>
  <img src="/images/hero-key-art.webp" alt="Night storm over land with one amber porch light on" />
</Frame>

Porch Light is a county emergency operator's **call-first** workflow. Pick a real warning area, get a ranked facility list with phones and reasons, inspect the evidence, mark contact status yourself, and export. No call or message is sent automatically. The priority formula is a transparent prototype heuristic, not a clinically validated order.

## Honest bar

- Contact status defaults to **Not contacted**. **Reached** is stored only when an operator chooses it.
- Rank order comes from a fixed formula. Nemotron does not set the order.
- Sponsor labels link only to work that actually ran. See [Sponsors](/sponsors) and repo `metadata.json`.
