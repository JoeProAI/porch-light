## Route

1. Open `http://127.0.0.1:3101/operate` (no county query) — Milton walkthrough.
2. Read the warning identity and data-as-of stamps.
3. Select rank 1 (amber porch row). Open the evidence drawer: source joins, refusals, query identity when present.
4. Contact status starts as **Not contacted**. Change it only for a call you actually made. **Reached** is never the default.
5. Export print/CSV when you need a paper trail. Nothing auto-dials.

## What is real here

- Facilities and phones come from the audited Manatee snapshot path, not invented demo rows.
- Reasons may include Nemotron drafts for early ranks when a Meterless receipt exists; remaining rows use computed reasons. Ranking stays formula-driven.
- Storm Watch / radar are separate surfaces. A missing radar tile must say so — never paint a decorative storm as live echo.
