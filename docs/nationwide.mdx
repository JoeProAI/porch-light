`/nationwide` is the product. On [porchlight.earth](https://porchlight.earth/nationwide) a click opens a frozen audited snapshot. It does not start a new Zetaris job and it does not call Nemotron.

## Open a county

`GET /api/national?county=02020` (five-digit FIPS) returns `phase: completed`, `publication.mode: published_sweep_snapshot`, and the county JSON. The same bytes are `web/data/national/published/counties/02020.json.gz`.

The page copy tells you hosted clicks open frozen snapshots and live model POST stays local. The button label is **Open published audited call sheet**.

`GET /api/national?recent=1` returns up to 20 published counties, highest ranked-facility count first. On the same check, the first row was Los Angeles County, California, FIPS `06037`, 450 ranked facilities, `generated_at` equal to the pack time. The list does not invent counties.

## The county the host will not open

Robertson County, Texas, FIPS `48395`, is in the catalog as `runtime_error` with 0 source rows and 0 ranked rows. There is no `48395.json.gz`. Live `GET /api/national?county=48395` returned HTTP 503:

```json
{"error":"No published audited snapshot is available for this county. No substitute data was returned.","unreachable":false}
```

The sweep report keeps the first-pass JDBC failure and a separate retry (2 ranked facilities, 1 refusal). The retry is not this hosted file. An empty or missing county is not proof that no care facility exists there.

## Alerts

Choosing **Captured live alert** on the hosted catalog throws: `Live alert runs stay on local origin. Choose a published county on this host.`

A fresh alert run is a local job. Storm Watch (`/watch`) reads the weather capture on that machine. On the public host, treat weather as supporting context only when the page shows a capture time. If the catalog says alerts are unavailable, say that.

## Local jobs

On `127.0.0.1`, with the published pack absent, `GET /api/national` reads the local Zetaris catalog and `POST /api/national` can start `engines.national_jobs`. If Zetaris cannot be reached, the UI says so and returns no rows. A bad FIPS does not load the Manatee sheet.

See [Local run](/local-run).
