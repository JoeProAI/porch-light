## Open a county

The address `/nationwide?county=` plus a five-digit FIPS selects that catalog row and, on the hosted desk, loads the published snapshot. You can also search by name or pick a state and county. Ambiguous names ask you to choose. `Dona Ana` matches Doña Ana.

The button label on a published host is **Open published audited call sheet**. The fine print under the catalog count cites the Zetaris query ids and the sweep id.

**Published ranked counties** lists 20 counties, highest `ranked_rows` first. That list is not the whole catalog. Los Angeles County is 450 ranked rows, Cook is 212, Harris is 140.

**Captured live alert** on this host does not start a job. The weather block is `unavailable`, and the client tells you live alert runs stay on local origin.

## Catalog totals

3,235 official entries. 2,490 `complete_with_ranked_rows`. 391 `complete_no_rankable_rows`. 353 `complete_no_matching_source_rows`. 1 `runtime_error` (Robertson `48395`). Query id `833`.

On the local machine, the same URL starts `engines.national_jobs` instead of reading the pack. If Zetaris is down, the page says so and does not load Milton. `/operate?county=` redirects here, so a bad county code cannot fall through to the Milton sheet.

A local smoke session is written up in `docs/smoke-national-results.md`. Those job ids are local checkpoints. They are not required to open the hosted snapshots.
