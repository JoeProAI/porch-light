Rank is a fixed formula. The same inputs produce the same order. Nemotron writes the draft beside the row. Contact status does not change the score.

Weights live in `data/scoring/weights.yaml`. The national screen is the object `national_source_screen`. `engines/national_run.py` checks it against `data/scoring/national_weights.json`.

## National sheet

Formula version on every hosted county row: `national-source-screen-v1`.

| Term | Weight | What the drawer calls it |
| --- | ---: | --- |
| `type_weight` | 0.35 | Facility type |
| `svi_pct` | 0.30 | Neighborhood vulnerability |
| `empower_density_pct` | 0.20 | Medical-equipment orders in this ZIP |
| `cms_risk` | 0.15 | Medicare rating risk |

There is no `plan_flag`. The snapshot limit says the national policy omits county plans, does not import the archived Manatee plan, and does not substitute zero.

`policy.clinical_validation` is false. The drawer says the total is a prototype on a 0 to 1 scale.

Example, live Doña Ana rank 1 (USRC Las Cruces, CCN `322559`): total `0.88278`, with type input 1.0, SVI input 0.9426, and the emPOWER term taken from published ZIP context. The ZIP counts are not a count of that facility's patients.

## Milton sheet

Formula version: `manatee-development-v1`.

| Term | Weight |
| --- | ---: |
| `type_weight` | 0.30 |
| `svi_pct` | 0.25 |
| `empower_density_pct` | 0.20 |
| `cms_risk` | 0.15 |
| `plan_flag` | 0.10 |

That fifth term is why the Milton order is not the national Manatee order. See [Milton retrospective](/manatee-walkthrough).

## Ties and refusals

The drawer prints `score.tie_break` for the row. Rows that fail an exact Census address match, lack a usable CMS rating, or otherwise fail a source rule appear in `refused`, with the rule name. They are not given a guessed rank.

A county outcome of `complete_no_matching_source_rows` or `complete_no_rankable_rows` is an empty ranked list plus the recorded gap. The UI does not borrow another county's rows.
