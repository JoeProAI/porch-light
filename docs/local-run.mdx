The recording path does not need this page. Published counties open on [porchlight.earth](https://porchlight.earth). Use a local run when you are producing a new audit, a new draft, or a captured-alert sheet.

## What has to be up

| Piece | Address | Role |
| --- | --- | --- |
| Web app | `http://127.0.0.1:3101` | Next.js in `web/` |
| Zetaris | UI `http://localhost:3000`, JDBC `jdbc:zetaris:lightning@localhost:10000` | Licensed local bundle |
| Nightshift | `http://127.0.0.1:8088/v1` | Meterless route `meterless/deep` |
| PostGIS | datasource `porchlight_postgis` | Read-only source relations |

Copy `env.example` to a file outside git if you override a path. Names the code reads include `PORCHLIGHT_ZETARIS_ENV_FILE`, `PORCHLIGHT_ZETARIS_JDBC_URL`, `PORCHLIGHT_ZETARIS_JDBC_JAR`, `PORCHLIGHT_ZETARIS_DATASOURCE`, and `PORCHLIGHT_DATA_ACCESS_MODE`. The NVIDIA key goes in Nightshift Providers. The app does not read `NVIDIA_API_KEY`.

Leave `PORCHLIGHT_OPENROUTER_BACKUP` unset.

## Start

From `web/`:

```bash
npm ci
npm run build
npm run start
```

On Windows, `.\Start-Local.ps1` from the repo root starts the built app when 3101 is free, and a weather worker when none is running. `-SkipWeather` leaves the worker off. The script does not install libraries, start Zetaris, or delete captures.

If Zetaris is unreachable, the nationwide page says so and returns no invented rows.

## Model route

Fast id: `nvidia/nemotron-3.5-lightning-30b-a3b`. Deep id: `nvidia/nemotron-3.5-super-vl-120b-a12b`. Both appear on `meterless/deep` receipts with thinking disabled. Local `meterless/local` is not a lane this submission demonstrates.

Scout Intent runs before a live call script. Batch explanation drafts are not on that gate. See [Meterless and Nemotron](/meterless-and-nemotron).

## Smoke

On a machine with Zetaris:

```bash
scripts/smoke-national.sh
```

The script reads the catalog and runs a fixed set of counties through `engines.national_run`. It does not spend the draft budget. A pass from the night of 2026-10-23 is in `docs/smoke-national-results.md`. If Zetaris is down, the script exits with that message and does not substitute another county.
