This page is intentional. Judges should see the gaps next to the working path.

## Product

| Claim people might assume | Actual status |
| --- | --- |
| Every US county has a polished offline sheet | **No.** Catalog search exists; completed local jobs are a small subset of 3,235 counties. |
| Contact **Reached** means someone was called | **Only if an operator chose it.** Default is **Not contacted**. |
| Nemotron picks who to call first | **No.** Fixed formula ranks; Nemotron drafts explanations / early reasons when receipts exist. |
| Clinically validated priority | **No.** Transparent prototype heuristic. Operator verification required. |
| Auto-dial or auto-SMS | **No.** Export and check-ins only. |

## Sponsor stack

| Gap | Why it matters |
| --- | --- |
| Meterless Engines (`Scout Intent`, `H-MEM`, World Model) | BUILD eligibility wants ≥1 engine powering a real feature. `metadata.json` currently lists `engines: []`. |
| Cursor eligibility evidence | Web authorship has been Devin-heavy; retain `.cursor/rules`, cloud agent PR links, and usage export before claiming Cursor credits. |
| Local Nemotron on GPU | Stronger for “best use of Nemotron” than a single hosted Super VL receipt. |
| Full Zetaris USL across many live physical systems | Not claimed. Audited JDBC + shared PostGIS path is what we show. |

## Data

Source vintages and refusals belong in the evidence drawer. Missing geometry is listed as missing — never guessed onto the map. Fabricated facilities, phones, or alert polygons are forbidden.
