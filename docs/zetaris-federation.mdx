Zetaris is the data path. National rankings were produced by audited SQL, and the query ids on the call sheet are those audit ids.

## Where it runs

The audit ran on the local Docker install: UI on port 3000, JDBC `jdbc:zetaris:lightning@localhost:10000`. The app's default datasource name is `porchlight_postgis`. Spatial predicates stay in PostGIS. Zetaris records the statement in `audit.public.sql_audit_log`, and `engines/zetaris_client.py` keeps that id.

The source relations are separate projections for CMS, Census, SVI, and emPOWER. They currently share one physical read-only PostGIS database. This submission does not claim a Unified Semantic Layer across several live systems, and it does not use the managed AWS route.

A browser on porchlight.earth does not log in to Zetaris. `GET /api/national` reads the published JSON. Each snapshot still carries `data_access_mode: zetaris`, the statement hash, the transaction id `zetaris-national-chain`, and the query ids from the run that created it.

## Measured joins

Match rates on a national `join_path` are `matched_count / candidate_count` from the Zetaris statement. They are not model confidence.

Hops written by `engines/national_run.py`:

| Hop | Method |
| --- | --- |
| Facility point into the county | `postgis_point_in_polygon` |
| Tract GEOID to SVI | `exact_key` |
| ZIP to emPOWER | `zip_to_empower` |

The source report totals those steps across the first pass. CMS to exact Census addresses and county coverage: 21,900 candidates, 16,326 matched, 5,574 unmatched. Tract to SVI: 21,900 candidates, 19,897 matched. ZIP to emPOWER, with fan-out counted: 21,900 candidates, 19,362 matched. Those are statement totals, not unique facility counts.

The OpenAPI contract also names `ssa_to_fips_crosswalk`, `census_geocode`, and `osm_admin_lookup` as legal methods. The national screen uses the three hops above. Global OSM lookups are not a shipped join.

## What a failed join looks like

A CMS row that misses the screen is a `refused` entry with a reason and the chain's query ids. It is not deleted. Robertson County's first pass failed before a snapshot was written (JDBC transport, 26.992 seconds in the source report). The hosted route returns 503 for that FIPS. The retry that later ranked two rows was not copied into the published pack.
