<Steps>
  <Step title="Open the nationwide desk">
    Go to [https://porchlight.earth/nationwide](https://porchlight.earth/nationwide).

    Home is nationwide-first: one amber link, **Pick any US county**. The page title is `Porch Light | Pick any US county.`
  </Step>
  <Step title="Read the catalog line">
    The fine print states the Census count, Zetaris catalog query `833`, sweep `20261023T200048Z-78a426ba`, and **2,490** counties with ranked facilities.

    Weather status on this host is `unavailable`. The message says live alert refresh stays on local origin. County discovery uses the published sweep catalog. Do not describe a captured alert on this host as a current warning.
  </Step>
  <Step title="Open Anchorage, then a passed draft, then Harris">
    Use these URLs in this order so the video shows a failure and a pass.

    1. [Anchorage Borough, Alaska, `02020`](https://porchlight.earth/nationwide?county=02020). 4 ranked, 2 refused, 6 source records. Rank 1 is Polaris Extended Care, CCN `025036`. The stored draft status is **failed**. The evidence drawer says no approved draft. Leave it failed.
    2. [Doña Ana County, New Mexico, `35013`](https://porchlight.earth/nationwide?county=35013). 7 ranked, 4 refused, 11 source records. Rank 1 is USRC Las Cruces, CCN `322559`. The stored draft passed on `nvidia/nemotron-3.5-lightning-30b-a3b` with `actual_usd` 0. Open the evidence drawer and read the source clauses.
    3. [Harris County, Texas, `48201`](https://porchlight.earth/nationwide?county=48201). 140 ranked, 96 refused, 236 source records. Rank 1 is DaVita North Houston Dialysis Center, CCN `452678`. The stored draft passed on `nvidia/nemotron-3.5-super-vl-120b-a12b` with `actual_usd` 0.

    The seven Zetaris query ids on each live response are listed on [Evidence trail](/evidence-trail). Anchorage starts at `9704`, Doña Ana at `3001`, Harris at `4343`.
  </Step>
  <Step title="Leave the contact control alone">
    The dropdown starts at **Not contacted**. Record an outcome only for a call you actually made. Do not save **Reached** for the video. Porch Light does not place calls or send messages. The record stays in this browser.
  </Step>
  <Step title="Do not press Generate on the public host">
    The button **Generate live Nemotron call script** is on the sheet. On `porchlight.earth`, `POST /api/national` returns HTTP 403 and this body:

    ```json
    {"error":"Same-origin local access is required for model operations."}
    ```

    That check was a refused POST on 2026-10-25 at 23:09 UTC. It did not start a model call. The draft you show is the one already stored on the row. A new script is a local-origin action. See [Meterless and Nemotron](/meterless-and-nemotron).
  </Step>
</Steps>

- The formula ranks. Nemotron writes the draft.
