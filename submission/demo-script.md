Recording plan only. No finished video is claimed. Use the existing local application and retained evidence. This documentation task does not authorize new model requests, source sweeps, calls or messages.

Primary action for the viewer: inspect the sourced call sheet and its evidence. Keep weather context brief.

## Open on the outreach workflow

Show the existing `/nationwide` workflow and a retained, verified county result when available. If it cannot be displayed without starting new work, show the named source report and label it as recorded evidence. Do not substitute Manatee for a national county result. `/operate` may be shown separately as the retrospective Manatee demonstration.

Say: "Porch Light is a sourced outreach workflow for dialysis centers and nursing homes. It puts directory contacts, inspectable ranking terms and source evidence into a call sheet. An operator verifies conditions and decides whom to contact."

## Inspect the source result

Select a facility and open its evidence. Show actual source references, query audits and rank terms. Show a real refusal or source gap if available. Do not invent a missing-data example or describe a captured alert as current.

Say: "The ranking comes from deterministic code. Missing source evidence stays visible. A directory phone is not a verified emergency contact, and an empty county result does not prove there are no facilities."

## Compare an accepted script and a retained failure

Show already retained script evidence without requesting another draft. Display the source references and actual model/attempt trace. Show the existing failure reason and linked retry. If only report evidence is available, identify it as report evidence on screen.

Say: "Meterless routes the draft request to NVIDIA Nemotron. The model selects allowed source clauses and verification questions. Validation checks those selections against the source evidence. Across the scoped checks, 18 script outcomes produced 16 passes and 2 retained failures, with $0 actual script request cost. The failures are still failures. Grounding is not clinical validation."

## Show the operator's next action

Show the contact controls and export or print view. Use a fresh browser session for a walkthrough. Do not save an outcome for a call that did not happen. If demonstrating a local interaction, label it as a demonstration and avoid presenting it as real outreach.

Say: "The operator makes the call and records the outcome. Porch Light does not call or message anyone. The record stays on this device, and the call sheet can be exported or printed."

If showing `/watch`, describe radar as supporting weather context. Show its source time and any stale or unavailable state. Do not use radar to imply verified facility conditions.

## Close on STATUS

Show the [status and evidence index](README.md#status) and the source report's recovery section.

Say: "All 3,235 counties have completed an audited source chain at least once. The original failure remains in the report alongside its separate recovery. The national model resume is running.
